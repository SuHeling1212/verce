# Verce

从与非门开始构建的 RV64GC 处理器。

## 主旨

现代计算机体系建立在层层抽象之上。操作系统运行在虚拟机上，虚拟机运行在宿主操作系统上，编译器编译编译器，CPU 里跑着微码。每一层都假设下面那层是正确的，每一层都依赖无数前人写好的代码。

Verce 试图切断这种依赖。它从唯一一个逻辑门——`!(a&&b)`——出发，不调用任何外部库，不使用硬件描述语言，不用综合器，不写一行 Verilog 或 VHDL。全部由 Java 实现，但 Java 只充当导线和电源——所有计算逻辑必须逐级展开，最终追溯到底层的与非门调用。

目标是在纯粹的逻辑门之上，构建一颗完整的、能运行 RISC-V 程序的 64 位处理器。

## 约束

- 零依赖。`import` 语句中不出现除 Java 标准库之外的任何内容。
- 所有硬件模块追溯到底层，其行为由且仅由 `!(a&&b)` 的真值表定义。
- 生成代码中不使用 `+`、`-`、`*`、`/`、`<<`、`>>` 、`if` 等 Java 原生运算符实现硬件运算逻辑。
- 生成代码中不使用 `for`、`while` 等循环语句构造硬件。所有结构全部手工展开为逐行门调用。用于减少手工劳动的代码生成脚本不受此限制，但其输出必须满足上述全部约束。

## 目标指令集

RV64GC：RISC-V 64 位基础整数指令集，包含 M（整数乘除法）、A（原子操作）、F（单精度浮点）、D（双精度浮点）、C（16 位压缩指令）扩展。

## 无内存架构

不模拟传统 RAM。存储层次中的所有状态——寄存器、缓存、主存——最终全部映射到文件。每次读写都是文件 I/O。关机不会丢失状态，开机即恢复现场。这是一种对"内存即状态"这一抽象的反向实验：如果内存不是瞬时可读写的电容器阵列，而是一块持久化的磁盘文件，计算机的运行方式会发生什么改变。
