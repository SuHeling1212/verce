# Verce

从与非门开始构建的 RV64GC 处理器。

## 主旨

从唯一一个逻辑门——`!(a&&b)`——出发，不调用任何外部库，不使用硬件描述语言，不写一行 Verilog 或 VHDL。全部由 Java 实现，Java 仅充当导线和电源——所有计算逻辑逐级展开，最终追溯到底层的与非门调用。

目标是在纯粹的逻辑门之上，构建一颗完整的、能运行 RISC-V 程序的 64 位处理器。

## 约束

- 零依赖。`import` 语句中不出现除 Java 标准库之外的任何内容。
- 所有硬件模块追溯到底层，其行为由且仅由 `!(a&&b)` 的真值表定义。
- 生成代码中不使用 `+`、`-`、`*`、`/`、`<<`、`>>`、`if`、`<`、`>` 等 Java 原生运算符或分支语句实现硬件运算逻辑。
- 生成代码中不使用 `for`、`while` 等循环语句构造硬件。所有结构全部手工展开为逐行门调用。

## 目标指令集

RV64GC：RISC-V 64 位基础整数指令集，包含 M（整数乘除法）、A（原子操作）、F（单精度浮点）、D（双精度浮点）、C（16 位压缩指令）扩展。

## 双包架构

| 包 | 实现方式 |
|---|---|
| `com.follarce.machine.cpu.ALU.RV64IMC` | 严格遵循上述约束，整数指令的所有运算从与非门逐级搭建 |
| `com.follarce.machine.cpu.ALU.RV64AFD` | 允许使用 Java 原生运算符和分支语句，实现浮点扩展 |

## 无内存架构

不模拟传统 RAM。存储层次中的所有状态——寄存器、缓存、主存——全部映射到文件。每次读写都是文件 I/O。关机不丢失状态，开机即恢复现场。
